# K M Jayaraj - Portfolio Website

A professional, futuristic portfolio website showcasing the skills, experience, and projects of K M Jayaraj, a Full-Stack Developer specializing in React and Microservices.

## 🚀 Features

- **Modern Design**: Futuristic dark theme with purple-cyan gradients
- **Responsive Layout**: Mobile-first design that works on all devices
- **Smooth Animations**: Scroll-based animations using Framer Motion
- **Interactive Elements**: Hover effects, parallax scrolling, and dynamic content
- **Professional Sections**: Hero, About, Skills, Experience, Projects, and Contact
- **Dark/Light Theme Toggle**: Dynamic theme switching
- **Contact Form**: Functional contact form for potential clients/employers

## 🛠️ Technologies Used

- **Frontend**: React 19 + TypeScript
- **Styling**: Tailwind CSS 4
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Build Tool**: Vite
- **Package Manager**: npm

## 📋 Prerequisites

- Node.js 18+ 
- npm 9+

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone <your-repo-url>
cd portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the development server
```bash
npm run dev
```

The website will open at `http://localhost:5173`

### 4. Build for production
```bash
npm run build
```

### 5. Preview production build
```bash
npm run preview
```

## 📁 Project Structure

```
src/
├── App.tsx          # Main application component
├── App.css          # Custom CSS styles and animations
├── index.css        # Tailwind CSS imports and base styles
├── main.tsx         # Application entry point
└── assets/          # Static assets
```

## 🎨 Customization

### Personal Information
Update the following in `src/App.tsx`:
- Name and title
- Contact information
- Experience details
- Project descriptions
- Skills and technologies

### Colors and Theme
Modify the color scheme in `tailwind.config.js` and `src/index.css`:
- Primary colors (purple-cyan gradient)
- Background colors
- Text colors
- Accent colors

### Animations
Customize animations in `src/App.css`:
- Scroll effects
- Hover animations
- Loading states
- Particle effects
